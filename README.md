# Personal AI Coach

A private daily coaching system designed around the user's goals, routines, mindset tools, anxiety reset, and gamified behavior system.

## Planned modules

- Daily check-in and guided routine
- AI coaching with persistent context
- Anxiety / overwhelm one-tap reset
- Goals and long-term identity
- Habits and workouts
- Gamified points and rewards
- Alcohol and other behavior tradeoffs
- Reflection, gratitude, meditation, and music
- Progress history and adaptive coaching

## Stack

- Next.js
- Supabase / PostgreSQL
- Vercel
- AI API integration to be added after the core app is working
